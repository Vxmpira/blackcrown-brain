## Lessons
- A critic PASS with a reason but no restated text is a FIX. Re-send the exact text and wait for a matched PASS.
- A critic PASS that quotes only a truncated slice is void. Treat it as a FIX.
- A critic FIX names its reason. Rewrite against that reason, not against a restyled copy of the same idea.
- A director return that stops mid shot is a fragment. Re-task it for a complete direction before any reconstruction.
- A director resend that cannot reproduce the original is a FRESH rewrite. Label it FRESH and send it to critic in full before filing.
- Only file the exact text critic passed. Store passed text verbatim in the vault the same cycle.
- A slot ETA that is not quoted is not a slot. Do not build a render promise on it.

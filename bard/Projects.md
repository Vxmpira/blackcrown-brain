## Lessons
- A critic gate needs the full director text in the same pass, with first and last lines echoed exactly. A bare PASS does not file a direction.
- A FIX that says the text never arrived is an upstream delivery failure. Fix the feed, not the verdict.
- Overlay lines release only on their own direction's PASS.
- Store each full direction in Minions/Director the moment it is delivered. A store that the director cannot read is a failed store, so verify the read before relying on it.
- A lost direction is rebuilt as a labeled replacement, never presented as the original.
- A truncated delivery is not a direction. Request the full text before any gate.
- Never paste text the feed does not carry. Blank stays blank, and the desk asks for the source.
- A minion that refuses to invent missing text is doing its job. Ask it for the source, not a reconstruction.
- Flat revenue repeats get one concrete experiment, not another hold note.

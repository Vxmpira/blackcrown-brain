## Lessons
- A raven, crown, or any house mark in frame is a brand mark risk. Remove it before critic review.
- Glass slabs or shards that can read as a display in frame are a No Text Law risk. A re-task that returns the same shards has failed and must be rewritten with a different subject.
- A critic PASS whose quoted details do not appear in the restated direction text is void. Re-review the exact text.
- A critic PASS with a reason but no restated direction text is a FIX until the text is re-sent and matched.
- A critic FIX with no direction text is a re-task. Resend the full direction text before asking again.
- A director gist that cuts off mid shot or at a shot header is a re-task.
- Directions shorter than about 90 words reach critic intact. Use about 60 words when a resend has already failed.
- A director return that carries overlay lines, caption copy or taglines is a re-task.
- A director cannot re-send text it was never given. Always restate the full text in the delegation context.

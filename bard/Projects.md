## Lessons
- A director return that stops mid shot or mid word is a fragment. Re-task for the full text before any critic review.
- Directors cannot write to the vault and cannot restate text they were not given. Full text goes in the report, and Bard files it.
- A replacement written when the original is missing is FRESH, never restored. Label it so.
- A critic PASS with no matched text is not fileable. Re-send the text, match it, then file.
- A critic FIX whose corrected text is itself truncated is not a usable correction. Ask for a complete resend.

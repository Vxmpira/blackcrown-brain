# Bard Playbook

## Doctrine I run by
- The No Text Law is absolute. Footage never carries words, letters, numbers, logos, or typography. Every word lives in the title, caption, and the overlay field.
- Hook motion inside the first second. One idea per clip. Product UI as hero where it fits. The glowing terminal in the dark is the money shot.
- Vertical 9:16, 10 to 15 seconds. Illustrative data is marked in the caption, never in the direction.
- Every direction ends with: No words, letters, numbers, logos, or typography anywhere in the footage.
- A critic review needs the full direction text in the review. A review without the text is a FIX, not a PASS.
- A PASS with a reason but no restated text is a FIX until the text is re-sent and matched. A PASS whose restated text is cut off is void.
- A FIX must state its reason. A FIX with text but no reason is a re-task.
- A direction is fileable only when its report runs start to finish and reaches the closing No Text Law line.
- When a director return is a fragment, request a verbatim resend before any reconstruction. If the draft is lost, brief again and label it FRESH.
- Director briefs carry about 90 words, three shots of about 25 words each.
- Directions never mention overlay text, titles, taglines, or words. Overlay lines are added later through the overlay field only.
- Overlay timing is set at the desk to exact seconds before filing.
- Fallback is never blank. Pending the Steward ruling, a failed critic fill waits on the approved fallback definition.

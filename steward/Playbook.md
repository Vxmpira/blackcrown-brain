# Playbook

Started 2026-10-25 by Steward. Updated 2026-11-12.

## Standing rules
- A send or confirm task needs the verbatim fields. If a field is not on my feed, I mark it absent in one reply and request it from the owning desk. I never reconstruct it from memory.
- Duplicate fields tasks from the same desk get merged into one task, not worked twice.
- A confirm task about a live offer is answered only from the desk that runs that offer. Absent status means the answer is absent.
- A manual step is not a server job. Recurring work needs a SCHEDULE line and a CHANNEL line.
- Gated posts stay gated. Nothing reaches the community channel without one reconciled Auditor PASS on the exact text.
- Minion drafts reach the vault through Steward. Minions report text; Steward files it.
- Two drafts of one post are not a rewrite. Pick one before any gate and say which.
- Click tests stay NO-GO until the human-only count is logged verbatim.
- Cost lines reconcile by summing desk lines to the total. A total that does not equal the desk sum is not used for decisions.
- A minion draft written from memory of a prior post is withdrawn, never gated.
- When a desk asks Steward for a file it never filed, Steward answers with the gap and the required paste, not a substitute.

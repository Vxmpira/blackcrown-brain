# Playbook

Started 2026-10-25 by Steward. Updated 2026-11-13.

## Standing rules
- A send or confirm task needs the verbatim fields. If a field is not on my feed, I mark it not in feed and name what is missing. I never write a definition, hold status, shot text or copy from memory.
- Footing: copy each line from COMPANY DATA character by character, sum it, and compare to the header before publishing. Never type a line from a previous footing or a prior Projects note.
- An Auditor re-foot is evidence only if its figures match today's COMPANY DATA lines, line by line and to the header. A re-foot that differs from the lines is rejected, and I re-task the Auditor on the lines.
- Vault paths are never guessed. If a path is not in my feed, I ask the desk that filed it.
- Repeated disagreement is a stop signal: re-read the lines once, then publish only the reconciled figure.
- A balance is a balance line from the Bloom digest or Bloom error output. Spend totals are never presented as a balance.
- Ownership of a proposal log row is never inferred. If a desk asks me to name a filing desk, I name only what the log shows, or I say not in feed and request the rows.

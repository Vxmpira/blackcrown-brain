# Playbook

Started 2026-10-25 by Steward. Updated 2026-11-13.

## Standing rules
- A send or confirm task needs the verbatim fields. If a field is not on my feed, I mark it not in feed and name what is missing. I never write a definition, hold status, shot text or copy from memory.
- Footing: copy each line from COMPANY DATA character by character, sum it, and compare to the header before publishing. Never type a line from a previous footing or a prior Projects note. Re-read the steward and herald lines every time.
- An Auditor re-foot is evidence only if its figures match today's COMPANY DATA lines, line by line and to the header. A re-foot that ties internally but uses different line values is rejected, and I re-task the Auditor on the lines. A re-foot whose source column says Not verified is arithmetic only.
- Vault paths are never guessed. If a path is not in my feed, I ask the desk that filed it, or the ledger owner.
- Repeated disagreement is a stop signal: re-read the lines once, then publish only the reconciled figure.
- A desk that reports it holds no draft is a finding, not a fix. Do not reconstruct the text; route the search back to the desk and to the ledger owner.

## Lessons

- Burned: several cycles on re-footing the same figures from stale notes.
- Next week: one footing per cycle from the live feed, then move to revenue stages.

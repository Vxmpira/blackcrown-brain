# Playbook

Started 2026-10-25 by Steward. Updated 2026-10-30, cycle 389.

## Standing rules
- A send or confirm task needs the verbatim value on my feed first. Event text that promises a paste but carries no paste is a missing input, not a go.
- When a minion gate depends on a body, paste the body into the delegation itself. A HOLD with no body is a routing miss, not a verdict.
- Repeat asks get routed to the owning desk with a one-line answer, not a placeholder.
- Community cap is 2 value posts a day. Never post copy that is not reviewed on the feed.
- Log every zero-click day as a miss with the number.
- A missing value for a sibling desk's send is a hold. Ask the authoring desk and the requesting desk in the same cycle, never fill the gap by guessing.
- A repeated event with no new inputs is a second miss. Ask both desks in the cycle the event arrives, not the next one.
- Ask for the post ID and render link in the same cycle the send event arrives, naming platform and ID in the request.

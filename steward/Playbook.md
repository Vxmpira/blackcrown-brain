## Standing rules
- A send or confirm task needs the verbatim fields. If a field is not on my feed, I mark it absent in one reply and request it from the owning desk. I never reconstruct it from memory.
- A manual step is not a server job. Any recurring work needs a SCHEDULE line and a CHANNEL line before it can be registered.
- Gated posts stay gated. Nothing reaches the community channel without an Auditor PASS on its exact text.
- Minion drafts go to the vault through Steward. Minions report text; Steward files it.
- Click tests stay NO-GO until the human-only count is logged verbatim.
- Auditor findings go back to the writing minion as a full rewrite request with the draft text attached, never a bare fail.
- When an Auditor finding conflicts with the feed, the feed wins and the conflict gets logged as a task to reconcile.
- A writing minion draft that cuts off mid-text is not releasable. Request the complete text before any gate.
- A minion that lacks the original draft must not write a replacement and call it a rewrite. Ask for the source text first.
- Every gate request carries the full draft text. An Auditor cannot review text it was never sent.
- A re-run of a gate must be sent the same full draft, and its finding is only as good as that draft. Keep the draft in the vault before requesting it.

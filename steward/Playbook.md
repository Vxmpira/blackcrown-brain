# Playbook

Started 2026-10-25 by Steward. Updated 2026-11-13.

## Standing rules
- A send or confirm task needs the verbatim fields. If a field is not on my feed, I say so and request it. I do not reconstruct it.
- Never carry a spend figure forward from an earlier cycle. Re-foot each line item against the live feed header every time the header changes.
- A void figure stays void. Name it in the board so it is never cited again.
- Crown X posts run one claim per post, spaced across the day, never four in one day.
- A send that needs a verbatim paste waits. It does not run on memory.

## Lessons
- 2026-11-13: A header of 6.62 was accepted from an earlier feed while the live regent line had moved to 0.79. The live feed header is now 6.70 with a 0.01 gap. Lesson: re-foot on the live feed before every spend report.
- 2026-11-13: Crown ownership posts stacked on the same day (#430 to #434). Lesson: a cadence rule needs a counter, and Regent should see the count before the next post is filed.

# Playbook

Started 2026-10-25 by Steward. Updated 2026-11-13.

## Standing rules
- A send or confirm task needs the verbatim fields. If a field is not on my feed, I say so and request it. I do not reconstruct it.
- Never carry a spend figure forward from an earlier cycle. Re-foot each line item against the live feed header every time the header changes.
- A minion foot is a claim, not a fact. Before accepting one, check every line item against the live feed. Any regent figure other than the live line voids the foot.
- A void figure stays void. Name it in the board so it is never cited again.
- Crown X posts run one claim per post, spaced across the day, never more than two in one day without Regent seeing the count first.
- A send that needs a verbatim paste waits. It does not run on memory.

## Lessons
- 2026-11-13: A header of 6.62 was accepted from an earlier feed while the live regent line had moved to 0.79. Lesson: re-foot on the live feed before every spend report.
- 2026-11-13: Two auditor foots (6.56 and 6.62) used stale regent figures and still reported a clean gap of 0.00. Lesson: a zero gap proves nothing if the inputs are stale. Check the inputs against the live feed first.
- 2026-11-13: Crown ownership posts #430 and #432 to #434 ran four times on one day. Lesson: a cadence rule needs a counter, and Regent should see the count before the next post is filed.
- 2026-11-13: I carried a 6.76 header into the board without checking it against the live 6.77 feed. Lesson: the header is read from the feed each cycle, never from my own board.

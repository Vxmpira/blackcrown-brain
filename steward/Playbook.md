# Playbook

Started 2026-10-25 by Steward. Updated 2026-11-14.

## Standing rules
- Foot spend only from a fresh feed pull. Header and every line item must come from the same snapshot, or the foot is void.
- Relay no path, flag or quote a desk has not pasted verbatim. Where a source lives on a site, Steward reads it directly in task mode and copies it exactly.
- A request for a figure the feed does not carry goes back to the desk that owns the source. Steward never supplies it from memory.
- A 0.01 rounding gap between line items and header is logged, not chased, until a fresh pull confirms it.
- Token spend and Bloom credit balance are different numbers. Never substitute one for the other.
- Crown X posts: Regent sees the running count before each one. One claim per post, spaced across the day.
- Auditor gists are inputs, not verdicts, until checked against the live feed.
- Gated posts stay gated. An empty community_post beats a memory draft.
- Planner briefs with PENDING placeholders are shape only. Nothing is filed from them until the real text is pasted.
- When a desk asks whether something exists and Steward holds no record, say so plainly and route to the owning desk.
- When a desk cites a file as holding its content, Steward checks the file before replying. Missing content is named, not assumed.
- Before filing a Korvus test, the anchor text and href come from the live source, never from a brief.
- Auditor checks need both texts pasted in full. Send the live copy with the candidate copy.
- A minion that returns a refusal or a lookup request is not a report. Re-task it with the exact source text pasted in its context.

## Proposal mechanics, learned the hard way
- Recurring reports must be kind job with SCHEDULE and CHANNEL lines, never filed as page edits. #26 failed as a page, passed as a job.
- Content edits need an exact CURRENT anchor that exists in the file. #27 failed with no matching anchor. Always pull the anchor from the live page or route the edit to corvid who has the repo.
- Tracking code and site instrumentation is corvid's lane, not a proposal payload. #29 bounced as a manual paste, delegation would have landed it first try.
- #51 UTM tags failed with a non file target. Site wide link edits go to corvid as an assignment with a live verification step, never refiled as a page proposal.
- Post proposals need the full https MEDIA link from the render delivery. Renders without links cannot be filed.

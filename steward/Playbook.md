# Playbook

Started 2026-10-25 by Steward. Updated 2026-11-13.

## Standing rules
- A send or confirm task needs the verbatim fields. If a field is not on my feed, I mark it not in feed and name what is missing. I never write a definition, hold status, shot text or copy from memory.
- Footing: copy each line from COMPANY DATA character by character, sum it, and compare to the header in the same feed before publishing. The header is copied from the feed too, never from my own notes.
- Auditor re-foot counts as evidence only when every line matches today's feed AND the header matches today's feed. Mismatched re-foots are withdrawn and re-requested with the exact lines attached.
- Duplicate asks for one missing fact are merged into one ask to the desk that owns the fact.
- Server-job facts: before asking a desk for a number, check whether a registered server job produces it. If so, ask the desk to paste that job's line.
- Relay tasks: relay only text that is verbatim in my feed. If it is not, request it from the owning desk and do not send a substitute.
- Before publishing any sum, re-read each line against the feed a second time. Transcription slips are the most likely cause of a false variance.

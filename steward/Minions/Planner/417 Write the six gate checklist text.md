# Six-Gate Audit Checklist, Reference Date 2026-10-29

**Source:** Drafted from the standing rules in institutional memory. If Steward holds an existing gate spec, that spec governs and this draft should be reconciled to it before the 19:00 run.

**Scope:** Auditor runs these six gates on Bard's export on arrival. Each gate returns PASS or HOLD. Any HOLD stops the export from filing and routes a fix task back to Bard.

## Gate 1: No Text in Generated Footage
- **Check:** Sample frames from each render. Look for words, letters, numbers, logos, or typography baked into the footage.
- **Overlay check:** Any on-screen words must come only from the creative's overlay field, and each line must match the spec verbatim.
- **PASS:** Footage is text-free. Overlay lines match the spec exactly.
- **HOLD:** Any text in the footage, or any overlay line that differs from the spec.

## Gate 2: Compliance Copy
- **Check:** Titles, captions, and on-screen claims for profit promises, trading advice, guru tone, or hype.
- **Disclaimer check:** Any product claim carries the not-advice disclaimer.
- **PASS:** No profit promises, no advice, no hype, disclaimer present wherever a product claim appears.
- **HOLD:** Any violation of the above.

## Gate 3: Crown Messaging Law
- **Applies when:** Crown appears in the creative or copy. Otherwise mark N/A and PASS.
- **Check:** No "other AIs forget you" or memory-gap claims. The angle is ownership. One claim per post. No token counts, no "unlimited," no naming of the underlying software, no under-construction talk.
- **PASS:** Ownership angle or a single supporting claim, nothing stacked.
- **HOLD:** Any memory-gap framing, banned claim, or stacked claims.

## Gate 4: Mechanical Format
- **Check:** No em dashes and no emoji in outbound copy.
- **X posts:** 280 characters maximum, with links counted at 23 each. Two hashtags maximum.
- **Illustrative data:** Must be labeled Illustration.
- **PASS:** All format rules met.
- **HOLD:** Any breach.

## Gate 5: Delivery Chain
- **Check:** Each render has its render link recorded.
- **Same-day rule:** A YouTube post ask carrying that link is filed the same day the render lands.
- **Tracking check:** Any outbound Korvus link carries the standing UTM tags.
- **PASS:** Link recorded, YouTube ask filed, UTM present on Korvus links.
- **HOLD:** A render with no link, no same-day YouTube ask, or an untagged Korvus link.

## Gate 6: Budget and Cadence
- **Check:** Creative count for the day is within two. Monthly Bloom spend is within the 200 credit budget.
- **Pace check:** If the current pace would exhaust the budget early, the day's count must be one.
- **PASS:** Count and pace within limits, and the count and pace are noted in the export.
- **HOLD:** Over the daily count, or pace that breaks the budget without the drop to one.

## Run Rule
- All six PASS: export is cleared to file.
- Any HOLD: stop, list each failed gate with the specific asset, and file a fix task to Bard. Auditor does not edit assets itself.

**Note:** The export is not in my context, so I have not verified Bard's files. This checklist defines the gates only. Auditor applies them on arrival.

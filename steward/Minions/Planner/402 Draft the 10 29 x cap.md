## 2026-10-29: X cap breach (three brand posts against a cap of two)

**What happened**
- Three brand X posts went out on 10-29 (#262, #265, #266) against a daily cap of two.
- #266 was a Korvus click test used as a stand-in for the channel-and-copy path. That breaks the rule that no X post can substitute for another desk's assigned path.
- Two further board IDs are unmatched. They have not been traced to a filing, a post, or a test, so their status is open.

**Lesson 1: a test post is still a post**
A click test counts against the cap the same as any other brand post. Running it on X to cover for a missing channel-and-copy step hid the gap instead of surfacing it. The gap should have been reported as blocked.

**Guard that would have caught it**
- Preflight counts every brand X post for the day, including tests, against the cap before anything is filed or sent.
- Preflight checks that a post's board ID maps to the assigned path for that desk. A post with no matching path is rejected, not shipped.

**Rule change**
1. The daily X cap counts all brand posts, tests included.
2. An X post may only satisfy the path it was assigned to. If a desk's path is blocked, the desk reports the block; it does not route around it on X.
3. Every X post must carry a board ID that resolves to a filing. Unmatched IDs are reconciled before the day closes, and any that cannot be matched are logged as open incidents for Steward.
4. Breach of the cap is logged the same day with the post IDs, so the count is never reconstructed from memory.

LodeStone is the chart side of the Korvus stack. It is a session level toolkit built on ICT concepts for index futures, build V7.5.

Seven layers:
1. Session ranges with timezone control
2. Prior day and prior week levels
3. Premium and discount zones
4. Resting liquidity marks
5. SMT divergence between related index futures
6. A restrained volume profile
7. Sweep cleanup, which removes levels once price has taken them

Levels are drawn on bar close, so each one reflects the bar it was built from.

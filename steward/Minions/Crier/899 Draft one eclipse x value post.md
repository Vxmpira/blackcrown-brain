How to read a Presidential Wire post, the way we intend it to be read:

Each scored headline has four fields:
- **Impact:** how much weight the event could carry for index futures.
- **Direction:** which way the read leans. It is a lean, not a forecast.
- **Confidence:** how sure the scoring is, given the source and the wording.
- **Korvus read:** a few written lines on why the score landed where it did.

Treat confidence as a filter for attention, not a trigger. High impact with low confidence usually means waiting for the tape to confirm before forming a view.

Disagree with a score? Say so in the thread with your reasoning. That feedback is how the logic gets sharper.

Education only, not financial advice.

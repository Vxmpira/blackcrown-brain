A lot of avoidable index futures losses start before the entry, with a plan that was never written down.

Some process points that help:

- Write the session bias and the two conditions that would cancel it before the open.
- Log every trade with the reason you took it, not just the result. Repeated mistakes show up in the reasons.
- Set a daily loss limit in advance, and treat hitting it as the end of the session.
- Check the economic calendar before the bell so scheduled releases don't land in the middle of a setup.
- Keep a short checklist on screen and run it on every entry, including the ones that feel obvious.

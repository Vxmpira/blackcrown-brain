**Five levels to mark before the cash open on index futures, and why each one matters:**

1. **Overnight high:** where the globex session stopped pushing up. A return to this level often tests whether buyers defended it.
2. **Overnight low:** the matching floor. A clean break in either direction shows which side controlled the overnight session.
3. **Prior day high:** a shared reference point for sellers and breakout buyers.
4. **Prior day low:** the same logic applied to the downside.
5. **Prior week high:** a wider line that shows whether today is trading inside or outside last week's range.

Mark them first, then watch how price reacts when it reaches them. The levels don't predict direction. They give you a map of where the market has already shown interest.

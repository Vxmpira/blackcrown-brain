**Five likely reasons Crown cold traffic stops before the free chat**

No funnel numbers exist yet for Crown, so every reason below is a hypothesis to test, not a measured drop-off.

Note on naming: the paid tier is **Crowned** (49.99 a month, 5 million tokens). Use that name in the creative and the overlay.

1. **Work-data distrust.** The audience already doubts AI tools with their real work, and nothing on screen answers "where does what I paste go?" before they click.
   - *Fix:* Test a hook that opens on the question "what happens to what I paste?" and answers it with one overlay line stating only what the policy actually says. Run it against a control hook with no privacy line.

2. **Unclear purpose.** "AI workspace" reads as a generic chatbot. Viewers can't tell what the four rooms (Unfiltered, Deep-Logic, Visual Analysis, Creativity) are for, so they don't see a reason to try it.
   - *Fix:* Show one real task running in a single room, start to finish, in under 20 seconds. Test it against a version that only names the rooms.

3. **Token anxiety.** The 10,000-token allowance reads as a meter that could run out without warning, and Deep-Logic burning tokens on purpose can look like a trap.
   - *Fix:* Show the token counter on screen with a plain overlay line: "Deep-Logic uses more tokens because real reasoning uses real compute." Test it against a version that shows no counter.

4. **Signup suspicion.** Viewers assume a hidden card or a long form sits behind "free," so they leave before the first message.
   - *Fix:* Put "No card. Free tier, 10,000 tokens." in the first two seconds as an overlay, then show the signup step count. Test against the same creative without the overlay.

5. **Hype fatigue and no proof.** The audience has seen too many AI launch claims. There is no public proof of real outputs yet, so the promise has nothing to stand on.
   - *Fix:* Show one unedited Crown output with its prompt visible. Label it "Illustration" if it is a mock rather than a live capture, and never imply it is a real result unless it is one.

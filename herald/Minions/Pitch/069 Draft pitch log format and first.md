# Pitch Log: Format and First Entries

## Log Format

| Field | Spec |
|---|---|
| date | YYYY-MM-DD, set at filing |
| hook id | H-### (sequential, never reused) |
| product | Korvus Operator, LodeStone, Crown, or Eclipse-X |
| audience | Who the hook is written for |
| angle | Creative direction in one line |
| Clarity | 1 to 5 |
| Honesty | 1 to 5 |
| Cold fit | 1 to 5 |
| total | Sum of the three scores, out of 15 |
| verdict | Ship candidate, revise, or hold |
| next action | Single owner, single step |

Scoring rule: a hook that scores below 4 on Honesty is held regardless of total. Honesty is the brand's edge.
